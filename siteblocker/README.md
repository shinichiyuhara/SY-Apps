# SiteBlocker

A private, local website blocker for Chrome (Manifest V3).

## What it does

- One-click block/unblock from the toolbar; block-list or allow-list (whitelist) mode.
- Match sites by domain, wildcard, keyword, or regular expression, with time-window schedules.
- Focus timer (Pomodoro) that enforces blocking, with optional ambient sounds and a full-screen timer.
- Hide distracting on-page elements (feeds, comments, Shorts, sidebars) with per-site toggles, a
  master switch, a temporary pause, and custom CSS selectors.
- Optional block screen with public-domain artwork and quotes.
- Optional local time tracking (host names and daily totals only). Optional password protection.

## Install

Add SiteBlocker from the Chrome Web Store (also works in Brave and other Chromium browsers). For
development, load the unpacked extension from `chrome://extensions` with Developer mode enabled.

## Privacy

No accounts, no servers, no analytics, no data collection. Everything is stored locally in your
browser; optional time tracking keeps host names and daily totals only and can be turned off. See the
[full privacy policy](privacy-policy.md).
