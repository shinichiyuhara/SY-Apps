# Privacy Policy — Kineion

Last updated: 2026-05-24

Kineion ("the app") is a video library manager for macOS. It does not transmit any data over the network and does not share anything with the developer or third parties.

## What we don't do

- We do not collect or send any personal data off your Mac.
- We do not use analytics, crash reporting services, or advertising SDKs.
- We do not ship with any network entitlement; the app cannot reach the internet for telemetry, automatic updates, or anything else.
- We do not modify the video files in your Library folders — Kineion reads them; it never writes back into the source tree.
- We do not share anything with the developer or any third party.

## What is stored locally

Everything below lives only on your Mac. The App Store build stores data inside the app's sandbox container (`~/Library/Containers/com.shinichiyuhara.Kineion/`); the developer build uses the equivalent paths under `~/Library/`.

- **Library catalogue (SQLite database)** — for every Library and every video the app has indexed: Library folder reference (as a security-scoped bookmark, see below), display path, file path, size, modification timestamp, AVFoundation metadata (duration, resolution, codec), and your annotations (tags, 5-star rating, favorite flag, watched flag, free-form notes). Stored at `Data/Library/Application Support/Kineion/library.db` (GRDB.swift / SQLite WAL).
- **Security-scoped bookmarks** — when you add a Library folder, macOS issues a bookmark blob that Kineion stores in the `library` table. The bookmark lets the app re-resolve the folder URL across launches without prompting you again, and is the only way a Sandbox build can read your selected folders.
- **Thumbnail cache** — JPEG thumbnails and 5×4 contact sheets generated by the in-app pipeline (QuickLook → AVFoundation → optional in-process FFmpegKit when linked) under `Data/Library/Caches/Kineion/Thumbnails/`. Rebuilt on demand if cleared. A subprocess-ffmpeg fallback exists for developer builds only; the App Store sandbox blocks it and it is never invoked from a shipping build.
- **Preferences** — display language, default view mode, tile size, keybindings, detected external player paths (IINA / VLC / mpv / QuickTime Player / Movist / Movist Pro), logging toggles, and other Settings values. Stored in macOS `UserDefaults` (`Data/Library/Preferences/com.shinichiyuhara.Kineion.plist`).
- **Diagnostic log** *(general logging on by default during early releases; high-frequency “verbose” logging off by default — both controlled in Settings → General)* — `~/Library/Logs/Kineion/kineion.log`, rotated past 5 MB with one previous generation kept. Records app lifecycle, database queries, scanner progress, thumbnail pipeline tier transitions, metadata extraction failures, and external-player launches. Unified system log (`os.Logger`) also receives a copy; the unified log uses `privacy: .public` so entries are visible in `log show` for diagnostics, but every filesystem path emitted is first passed through `Logger.redact(path:)` which masks `/Users/<name>` → `~` and `/Volumes/<label>` so the account name and volume label never appear in the log.

Kineion does not use the macOS Keychain. There are no passwords to store.

## How to delete the data

- Right-click a Library → "Remove" deletes the `library` row and cascades to its `video` rows.
- For a complete wipe, quit Kineion and remove the sandbox container:
    `rm -rf ~/Library/Containers/com.shinichiyuhara.Kineion`
    `defaults delete com.shinichiyuhara.Kineion`
    Uninstalling the App Store build via Finder / Launchpad also removes the sandbox container.

## Privacy manifest

The bundled `PrivacyInfo.xcprivacy` declares `NSPrivacyTracking = false` and no collected data types. The only declared API categories are file timestamp, disk space, and UserDefaults access — each used solely to display attributes of files you supplied and to persist Kineion's own settings.

## Children

Suitable for ages 4+. The app provides no content of its own — it indexes video files you supply. No advertising, no in-app purchases, no links to external services beyond the App Store itself.
